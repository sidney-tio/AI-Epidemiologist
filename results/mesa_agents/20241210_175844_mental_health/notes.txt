## Plot Descriptions

### Model Results Plot (model_results.png)
This plot shows the evolution of various model-level metrics over time for each run. Each subplot represents a different metric, such as the Gini coefficient, which measures wealth inequality among agents. The x-axis represents the timesteps, and the y-axis represents the value of the metric. The different lines in each subplot correspond to different runs, allowing for a comparison of how each intervention impacts the overall model metrics.

### Agent Results Plot (agent_results.png)
This plot shows the average values of various agent-level metrics over time for each run. Each subplot represents a different metric, such as the average wealth of agents or the average number of steps not given. The x-axis represents the timesteps, and the y-axis represents the average value of the metric across all agents. The different lines in each subplot correspond to different runs, allowing for a comparison of how each intervention impacts the behavior and state of individual agents.
